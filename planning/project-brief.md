# 项目约定

## 已确认

| 项目 | 说明 |
| --- | --- |
| 使用场景 | 师范生“教学方法”课程的课程作业 |
| 主题 | 中学数学：因式分解 |
| 讲课时长 | 10 分钟 |
| 配套材料 | 教案、演示文稿、板书设计；配套例题与练习统一管理 |
| 工作区 | D:/FactorizationTeaching |
| 最终交接方式 | 通过 GitHub 仓库交接，远端仓库信息由用户后续确定 |

## 初始设计假设

- 学段暂按初中处理，学习者已接触乘法分配律、单项式与多项式相乘。
- 选取“从乘法分配律到提公因式法”作为 10 分钟教学片段。
- 内容集中在识别公因式、提取公因式与展开检验，公式法等内容放在后续可扩展模块。
- 讲课使用问题引导、观察比较、例题示范与即时反馈，教案说明每种活动的具体作用。
- 以可编辑的教案、课件和板书源文件支持同学自行调整。

## 待确认

1. 年级、教材出版社、教材版次及对应章节。
2. 任课教师给出的作业题目、评分标准和提交格式。
3. 现场是否有同伴扮演学生，是否需要无生试讲或录课。
4. 10 分钟是否包含开场自我介绍、说课或课后答辩。
5. 是否限定“因式分解概念”“提公因式法”或其他具体课题。
6. 最终 GitHub 仓库归属、可见性、交接对象及文件命名要求。

## 制作目标

学生能够从具体例子解释因式分解的方向，能完成一道提公因式题并用整式乘法检验。教案中的教学目标、课堂活动和当堂检测逐项对应。
