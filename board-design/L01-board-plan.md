# L01 板书设计初稿

板书逐步形成，写入时间已计入统一的 600 秒预算。

## 最终布局

标题：因式分解——提公因式法

| 左区：概念与依据 | 中区：例题与步骤 | 右区：易错与检测 |
| --- | --- | --- |
| ab＋ac＝a(b＋c) | E03：6x²＋9x | E04：3x²＋3x |
| 和的形式 → 积的形式 | 公因式：3x | ＝3x(x＋1) |
| 依据：乘法分配律 | ＝3x·2x＋3x·3 | 提取后，对应项为 1 |
|  | ＝3x(2x＋3) | E05：8a²－12a |
|  | 检验：展开还原 | ＝4a(2a－3) |

底部归纳：找公因式 → 逐项确定商式 → 乘回检验。

## 书写顺序

1. 导入时短暂写 E01，完成过渡后将左区用于一般式。
2. 在 01:00—02:30 完成左区一般式与“和 → 积”。
3. 在 02:30—06:30 完成中区公因式、逐项改写与结果。
4. 在 06:30—08:00 处理右区 E04，保留正确结果和 1 的提醒。
5. 在 08:00—09:20 写右区 E05 的反馈结果。
6. 最后 40 秒完成底部三个动作。

## 书写与可读性

- 教师讲解与板书同步，写完关键等式后面向学生提问。
- 用圈画或单一强调色突出 3x 和易错常数 1。
- 每个等号保持与当前表达式相等；乘回检验另起一行。
- 预留右区给练习反馈，保持中央例题完整可见。
- 正式板书图需根据实际黑板比例调整，并保留可修改源文件。
